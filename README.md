# java-calculator-precourse

## 구현할 기능 목록 

### Application
- 사용자로부터 문자열을 입력받는다. 
- Calculator에 입력을 전달하고 결과를 반환받는다.
- "결과 : {숫자}" 형식으로 결과를 콘솔에 출력한다.
- 예외 발생 시 애플리케이션을 종료한다.

### Calculator
- 빈 문자열 입력시 0을 반환한다. 
- Parser, Delimiter, NumberValidator을 사용하여 계산을 수행한다.
- 모든 숫자의 합을 반환한다.

### Parser
- 입력 문자열에 커스텀 구분자가 포함되어 있는지 확인한다.
- 커스텀 구분자가 있다면 "//"와 "\n" 사이의 커스텀 구분자를 추출한다.
- 커스텀 구분자가 있다면 "\n" 이후의 숫자 부분 문자열을 추출한다.

### Delimiter
- 기본 구분자(",", ":")를 초기화한다.
- 커스텀 구분자를 추가한다.
- 모든 구분자를 사용하여 문자열을 분리한다.

### NumberValidator
- 문자열을 숫자로 변환한다.
- 빈 문자열을 0으로 처리한다.
- 음수 입력 시 IllegalArgumentException 발생시킨다.
